## 2. 프로젝트 배경
지구온난화로 인한 기후 변화로 소나기와 국지성 집중호우의 빈도가 급증하고 있으나, 전통적인 기상 관측 방식만으로는 갑작스러운 기상 변화를 실시간으로 예측하는 데 한계가 있어 도심지 침수와 안전사고의 위험성이 커지고 있습니다.
본 프로젝트는 네팔 카트만두의 10년간 기상 데이터를 활용해, 시계열 데이터 학습에 특화된 LSTM 모델 기반의 정밀한 강수량 예측 모델 개발을 목표로 하였습니다.
단순히 수치 예측에 그치지 않고, 예측 결과를 4단계 카테고리로 분류하여 상황별 맞춤형 AI 조언과 행동 요령을 함께 제공함으로써 실생활에서 실질적인 대비가 가능한 강수량 예측 서비스를 구축하고자 했습니다.

## 3. 기술 스택
- Python (3.12.6)
- scikit-learn, tensorflow, keras, LSTM, streamlit
- Streamlit Cloud

## 4. 주요 기능
- 기상 데이터 기반 입력 시스템
  - 사용자로부터 온도, 습도, 풍향 등의 기상 데이터를 입력 받아 모델 추론을 위한 입력 데이터로 처리
- LSTM 모델 기반 강수량 예측
  - 시계열 데이터 학습이 반영된 LSTM 모델을 통해 입력된 기상 데이터를 분석하여 강수량을 정밀하게 예측 후 제공
- 4단계 카테고리 분류 및 맞춤형 AI 조언
  - 예측된 수치를 4단계 카테고리로 나누어 판정하고 "우산을 챙겨요"와 같은 실생활 밀착형 행동 요령 및 AI 조언을 함께 제공
 
## 5. 모델 학습 및 비교
- **EDA 분석** : 변수별 분포도 분석, 변수 간 상관관계 확인 (다중공선성 분석)
- **데이터 전처리** : 결측치 확인, 원핫 인코딩, 스케일링, 불필요한 피처 제거
- 모델 성능 비교 및 베이스라인 모델 선정
  - 사용한 모델 : RNN, LSTM, BiLSTM, GRU
  - 최종 선택한 모델 : LSTM
  - 선택 이유 : 기상 데이터의 강수량이 0이 너무 많아 생긴 특성 때문에 모델 기본 구조 성능이 모두 유사하여 학습 속도가 빠르고 구조가 가벼운 LSTM을 선택
 
## 6. 트러블 슈팅
**1. 시계열 데이터 분포도로 인한 기울기 소실 문제**
- **문제 상황** : 분류 모델을 거친 뒤 회귀 모델에서 강수량을 예측했을 때 예측값이 모두 0이 나오는 문제 발생
- **원인 분석** : 시계열 데이터를 분할할 때 학습 데이터에 강수량이 0인 데이터가 너무 많이 들어가서 분류 모델을 지나고 회귀 모델에서 강수량이 무조건 0으로 예측되는 기울기 소실 문제가 발생
- **해결 및 성과** : 분류 + 회귀 모델 파이프라인 구조가 아닌 단일 LSTM과 Huber 손실 함수를 사용해 기울기 소실 문제 해결

**2. Streamlit Cloud 라이브러리 설치 실패 오류**
- **문제 상황** : Streamlit Cloud에서 서비스가 구현되는 과정에서 라이브러리 설치 실패 문제 발생
- **원인 분석** : Streamlit Cloud 내 파이썬 버전이 모델을 개발했던 버전과 달라 발생한 문제로 확인
- **해결 및 성과** : Streamlit Cloud 내 파이썬 버전을 3.14에서 모델을 개발한 버전인 3.11로 변경하여 해결

## 7. 실행 방법
**1. 저장소 클론 및 이동**
``` bash
git clone https://github.com/winterbar/predrain.git
cd predrain
```
**2. 의존성 패키지 설치**
``` bash
pip install -r requirements.txt
```
**3. Streamlit 앱 실행**
``` bash
streamlit run app.py
```

## 8. 기대효과
온도, 습도, 풍향 등 사용자가 직접 입력한 기상 데이터를 바탕으로 즉각적인 예측 결과를 제공하여, 복잡한 기상청 수치 데이터 없이도 누구나 손쉽게 비에 대비할 수 있는 환경 제공
